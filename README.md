# Zeeshan Rasheed — Portfolio

A modern, responsive, and interactive personal portfolio built with **React**, **Vite**, and **Tailwind CSS**. The portfolio showcases my skills, projects, and experience with a clean UI, smooth animations, and an engaging user experience.

---

## 🚀 Features

- ✅ Responsive Navbar
- ✅ Sticky Navigation
- ✅ Glassmorphism UI Design
- ✅ Animated Theme Toggle (Sky ☀️ ↔ Night 🌙)
- ✅ Smooth Sun-to-Moon Morph Animation
- ✅ Dynamic Background & 3D Scene Switching
- ✅ Hero Section
- ✅ Typing Animation
- ✅ Call-to-Action Buttons
- ✅ Social Media Integration
- ✅ Floating 3D Shapes with Parallax Effect
- ✅ Download Resume
- ✅ Fully Responsive Design
- ✅ Modern UI & Smooth Animations
- ✅ Contact form delivery through FormSubmit
- ✅ Reduced-motion and lower-cost 3D scene settings

## 📂 Installation

### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Navigate to the Project Folder

```bash
cd portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Your Browser

```text
http://localhost:5173
```

## ✉️ Contact form setup

The contact form uses FormSubmit instead of EmailJS and does not require API keys or a backend. On its first submission, FormSubmit sends a verification email to `zeeshan.mir.001300@gmail.com`; open that email and confirm the address before messages can be delivered. The form displays a success or error message after each submission.
