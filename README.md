# Zeeshan Rasheed — Portfolio (Phase 1)

Phase 1 mein ye ban chuka hai:
- Navbar (responsive, glassmorphism, sticky)
- Theme toggle (sky ⇄ stars) — sun morphs to moon, background + 3D scene dono badalte hain
- Hero section: typing effect, CTA buttons, social links, floating 3D shapes with parallax

## Run karne ka tareeqa

1. Terminal VS Code mein khol kar is folder mein jao:
   ```
   cd portfolio
   ```
2. Dependencies install karo:
   ```
   npm install
   ```
3. Dev server chalao:
   ```
   npm run dev
   ```
4. Browser mein `http://localhost:5173` khol lo.
